# ⏱️ 정밀 웹 메트로놈 (Precision Metronome)

피아노 연주자를 위한 **단일 HTML 웹 메트로놈**. 파일 하나만 올리면 바로 동작합니다.
외부 CDN·폰트·오디오 파일 의존성 0 — 모든 소리는 Web Audio API로 실시간 합성합니다.

- 파일: `index.html` (HTML·CSS·JS 전부 인라인)
- 한국어 UI / 모바일 우선(390px) ~ 데스크톱(1280px) 반응형 / 다크 + 피아노 골드·블루, 라이트 테마 전환
- **스크롤 없는 1화면**: 박자 시각화 · BPM · 재생 버튼이 한 화면에 들어오고, 세부 설정(빠르기말·박자·소리)은 시트(팝업)로 열린다
- SEO 메타태그(`title`, `description`, `keywords`, `og:*`, `twitter:*`, canonical) + 구조화 데이터(SoftwareApplication)
- 애드센스 슬롯 자리(`#ad-bottom`, 주석 처리된 빈 영역) — 배포 후 `hidden` 해제하고 `<ins>` 로 교체

## 1. 화면 구성 (한 화면)

```
┌ 미니 헤더 ─ 로고 · 제목 · 테마 토글 ┐
│ 1 / 4        [4/4] [세분박] [음색]  │  ← 박자 번호 + 배지
│ ▮ ▯ ▯ ▯  (박자 인디케이터 · 박을 누르면 강박→중강박→약박→무음) │
│ 강박 중강박 약박 무음      박을 눌러 강약 변경 │
│ TEMPO            Moderato · 보통 빠르기로 │
│ [−5][−1]  112 BPM  [+1][+5]        │
│ ─────●───────  [TAP]               │
│ [빠르기말 ▾] [박자 ▾] [소리 ▾]      │
│            ▶ 시작                  │
└────────────────────────────────────┘
```

- 박자 인디케이터 아래의 **마디 진행 바·펜듈럼은 두지 않습니다**(산만함 제거, 점등에 집중).
- **화면 플래시 효과 없음** — 소리와 박자 점등만으로 박을 알립니다.

## 2. 기능

### 🎚 속도(BPM) — 숫자 ↔ 빠르기말 양방향
| 항목 | 설명 |
| --- | --- |
| 범위 | **20 ~ 300 BPM** (슬라이더 전체 구간, 20/300 클램프) |
| 조절 | 슬라이더 · `−5` `−1` `+1` `+5` 버튼 · 숫자 직접 입력(3자리) · **Tap Tempo** |
| 빠르기말 | Grave 40 · Largo 45 · Larghetto 63 · Adagio 70 · Andante 90 · Moderato 112 · Allegretto 116 · Allegro 136 · Vivace 166 · Presto 184 · Prestissimo 208 |
| 연동 | BPM을 바꾸면 현재 구간의 빠르기말과 한국어 뜻이 실시간 표시(`Andante · 느리게 걷는 속도로`), 빠르기말 시트에서 고르면 그 BPM으로 이동 후 시트가 닫힘 |

### 🥁 박자표 — 모든 박자 선택 (박자 시트)
- 프리셋 8종: `2/4` `3/4` `4/4` `5/4` `6/8` `7/8` `9/8` `12/8`
- **분자 1~16박 전부** + **분모 2 / 4 / 8 / 16** 자유 선택 (선택 즉시 인디케이터 개수 반영)
- 세분박: 없음(1배) · 8분(2연음) · 3연음 · 16분(4연음) — 세분박은 약한 소리로 얹힘

### 🔊 박자별 소리 커스터마이징
- 화면의 각 박(1박~N박)을 누를 때마다 **강박 → 중강박 → 약박 → 무음** 순환
- 강세 프리셋(소리 시트): **첫 박만 강세** / **모든 박 동일** / **6/8 (1·4박 강세)**
- 음색 4종 — 실제 악기·기기 소리를 목표로 다시 설계한 **순수 파형 합성음** (새추레이션·드라이브 없음, 고주파 치찰음 없음)
  | 음색 | 설계 |
  | --- | --- |
  | **기계식 똑딱이** | 맑은 나무 공명. 강박 1150Hz · 약박 860Hz, 3ms 어택 + 28ms 바디. 트랜지언트는 나무 타격감만큼만(레벨의 16%) 남기고, 옅은 2배음 하나로 또렷함을 더한다 |
  | **디피 메트로놈** | 롤랜드 HP704·야마하 디피 내장 메트로놈처럼 찌르지 않는 순수 사인 벨. 4ms 소프트 어탁, 강박 C6(1046.5Hz) · 중장 G5(784Hz) · 약박 C5(523.25Hz), 2배음은 12%로만 |
  | **드럼 스틱** | 짧고 단단한 어쿠스틱 림 클릭. 노이즈 버스트는 레벨의 26%·박의 55% 길이로 줄이고, 820Hz 나무 몽통(45ms)과 1.75kHz 배음을 중심으로 깨끗하게 |
  | **소프트 클릭** | 삼각파 + 사인파 우드 톱(470~560Hz, 4ms 어탁). 2배음 22%에 여린 어택 성분 8%만 더해 찌르는 고음 없이 편안하게 |
- 마스터 체인(왜곡 소자 없음): 음색 버스 → **하이패스 180Hz**(폰 스피커 떨림 방지) → **로우패스 7kHz**(치찰음 방지)
  → 볼륨 GainNode(100% = gain 1.0) → **안전 리미터**(문턱 −1.2dBFS ≈ 0.871 · 20:1 · 천장 0.88)
  → 신호를 일부러 눌리거나 비틀지 않고, 합성 단계에서 피크를 0.79~0.82으로 설계해 헤드룸을 확보한다 (리미터는 평소 닿지 않는 안전장치)
- 기본 볼륨 **80%**, 0~100% 슬라이더는 선형 매핑(`gain = v/100`, 100% = 1.0)
- 무음 박은 스케줄 단계에서 소리를 만들지 않음

### ⏱ 타이밍 엔진
- `AudioContext.currentTime` 기준 **Lookahead 스케줄러**(`setInterval` 25ms + `scheduleAheadTime` 0.1s)
- 재생 버튼에서 `audioCtx.resume()` 처리 → iOS Safari 자동재생 정책 대응
- 백그라운드 탭에서는 lookahead를 1.5s로 늘려 setInterval 스로틀(1s)에도 박이 끊기지 않게 처리
- 재생 중 BPM을 바꿔도 다음 박 스케줄 기준 시각을 보정해 위상이 튀지 않음

### ⌨ 편의
- `Space` 시작/정지, `↑`/`↓` BPM ±1, `Shift`+`↑`/`↓` ±5 (시트가 열려 있을 때는 BPM 단축키 무시)
- `Esc`·바깥 클릭·완료 버튼으로 시트 닫기
- `localStorage`에 BPM·박자표·세분박·박자별 강약 패턴·음색·볼륨·테마 저장/복원 (v1 음색 id 자동 변환)

## 3. 실행

```bash
cd projects/metronome
python3 -m http.server 8765
# http://127.0.0.1:8765/
```

`index.html` 더블클릭(file://)으로도 재생은 되지만, 브라우저에 따라 `localStorage` 가 막히므로 HTTP 로 여는 편이 좋습니다.

### 검증 · 스크린샷

```bash
export PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright
export LD_LIBRARY_PATH=/workspace/.browserlibs/root/usr/lib/x86_64-linux-gnu:/workspace/.browserlibs/root/lib/x86_64-linux-gnu
python3 -m http.server 8765 &
python3 tests/verify.py        # 64개 항목 자동 검증
python3 tests/probe_peaks.py   # 음색별 출력 피크·스펙트럼 빠른 계상(튜닝용)
python3 tests/make_previews.py # preview-*.png 생성
```

**검증 결과 (2026-11-27 · v2.1 클린 복구): 64/64 통과**
- 콘솔 에러·런타임 예외 0건, `createWaveShaper` 호출 0회 (새추레이션·드라이브 완전 제거)
- 오디오 시계 기준 박 간격 240 BPM → `0.2500s` 정확히 유지, 화면 점등 평균 250ms
- 3연음 세분박 간격 `0.0833s`, 무음 박은 스케줄에서 제외
- 모바일 390×844: `scrollHeight 844 = viewport 844` (세로 스크롤 없음), `scrollWidth 390` (가로 스크롤 없음)
- 음색 4종 출력 피크(볼륨 100%): 0.789 / 0.822 / 0.816 / 0.798 — 0.75~0.88 클린 범위, 1.0 미달
- 최고 밀도(300 BPM · 16분 세분박): 피크 0.776 — 겹침에서도 헤드룸 유지
- 스펙트럼: 6kHz 이상 비중 0.1~1.5%, 중심주파수 0.9~1.8kHz

## 4. 배포 메모

- GitHub Pages 등 정적 호스팅에 `index.html` 하나만 올리면 동작합니다(경로 의존성 없음).
- canonical/OG URL 은 `https://ehoondev.github.io/metronome/` 로 적어 두었으니, 실제 배포 주소가 다르면 `<head>` 의 URL 3곳을 바꿔 주세요.
- 애드센스: `<footer>` 의 `#ad-bottom` 주석 위치에 `<ins class="adsbygoogle" …>` 를 넣고 `hidden` 을 제거하면 됩니다.
