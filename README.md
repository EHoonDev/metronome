# ⏱ 정밀 웹 메트로놈 (Precision Metronome)

**바로 쓰기 → https://ehoondev.github.io/metronome/**

피아노 연주자를 위한 **단일 파일 웹 메트로놈**입니다. 설치도, 로그인도, 외부 라이브러리도 필요 없습니다 —
`index.html` 하나에 HTML·CSS·JS가 모두 들어 있고, 소리는 Web Audio API로 그때그때 합성합니다.

- 파일: `index.html` (외부 CDN·폰트·오디오 파일 의존성 0)
- 한국어 UI / 모바일(390px)부터 데스크톱(1280px)까지 반응형 / 스튜디오 다크 + 피아노 골드·블루, 라이트 테마 전환
- **스크롤 없는 1화면** — 박자·BPM·재생 버튼이 한 화면에 들어오고, 세부 설정(빠르기말·박자·소리)은 시트로 열립니다
- SEO 메타태그와 OG 공유 이미지, 구조화 데이터(SoftwareApplication) 포함
- PC·태블릿·휴대폰 브라우저에서 바로 동작합니다(설치·회원가입 불필요).

## 기능

### 🎚 속도(BPM) — 숫자와 빠르기말 양방향
| 항목 | 설명 |
| --- | --- |
| 범위 | **20 ~ 300 BPM** |
| 조절 | 슬라이더 · `−5` `−1` `+1` `+5` 버튼 · 숫자 직접 입력 · **Tap Tempo** |
| 빠르기말 | Grave 40 · Largo 45 · Larghetto 63 · Adagio 70 · Andante 90 · Moderato 112 · Allegretto 116 · Allegro 136 · Vivace 166 · Presto 184 · Prestissimo 208 |
| 연동 | 빠르기말을 누르면 해당 BPM으로 이동하고, BPM을 바꾸면 현재 구간의 빠르기말과 한국어 뜻이 함께 표시됩니다 (`Andante · 느리게 걷는 속도로`) |

### 🥁 박자표 — 원하는 박자를 그대로 (박자 시트)
- 프리셋 원클릭: `2/4` `3/4` `4/4` `5/4` `6/8` `7/8` `9/8` `12/8`
- **분자 1~16박 전부** + **분모 2 / 4 / 8 / 16** 자유 선택
- 세분박: 없음(1배) · 8분(2연음) · 3연음 · 16분(4연음) — 세분박은 약한 소리로 얹힙니다

### 🔊 박자별 소리 맞춤
- 화면의 각 박을 누를 때마다 **강박 → 중강박 → 약박 → 무음** 순환, 박마다 다르게 지정
- 빠른 프리셋: **첫 박만 강세** / **모든 박 동일** / **6/8 (1·4박 강세)**
- 음색 4종(모두 합성음, 실제 악기·기기 소리를 목표로 재설계)
  - **기계식 똑딱이** — 실제 메트로놈의 나무 타격 트랜지언트(6~8ms) + 760~1040Hz 공명 바디(52~78ms)
  - **디피 메트로놈** — 디지털 피아노 내장 메트로놈처럼 부드러운 사인 벨(C6/G5/C5, 50ms 디케이)
  - **드럼 스틱** — 녹음실 스틱 카운트, 1.3~4.2kHz 어쿠스틱 틱 + 700~780Hz 나무 몸통
  - **소프트 클릭** — 피아노 건반 소리에 묻히는 둥근 우드 팝(2~3배음에 짧은 펀치)
- 마스터 체인: 11kHz 로우패스 → 드라이브 → 소프트 새추레이션 → 6.2kHz 로우패스 → 컴프레서 → 볼륨 → 소프트 리미터
  → 휴대폰 스피커에서도 충분히 큰 음량(볼륨 100% 피크 0.94~0.96, 디지털 클리핑 없음), 기본 볼륨 85%
- 무음 박은 소리를 만들지 않음

### 👁 화면 표시
- 박마다 점등·확대 애니메이션(강박·중강박·약박은 높이와 색으로 구분, 무음은 빗금)
- 큰 박자 번호 `1 / 4`, 박자별 인디케이터가 이 페이지의 전부 — 펜듈럼·마디 진행 바·화면 플래시는 넣지 않았습니다

### ⏱ 타이밍 엔진
- `AudioContext.currentTime` 기준 Lookahead 스케줄러(25ms 주기, 0.1초 미리 예약)
- iOS Safari 자동재생 정책 대응(`resume()` 처리)
- 백그라운드 탭에서도 박이 끊기지 않도록 lookahead 자동 확장
- 연주 중 BPM을 바꿔도 다음 박 스케줄 기준 시각을 보정

### ⌨ 편의
- `Space` 시작/정지, `↑` `↓` BPM ±1, `Shift`+`↑` `↓` ±5
- `Esc` · 바깥 클릭 · 완료 버튼으로 시트 닫기
- BPM·박자표·세분박·박자별 강약·음색·볼륨·테마를 브라우저에 저장해 다음 방문 때 그대로 복원

## 로컬에서 열기

```bash
git clone https://github.com/EHoonDev/metronome.git
cd metronome
python3 -m http.server 8765
# http://127.0.0.1:8765/
```

`index.html`을 더블클릭해도 소리는 나지만, 브라우저에 따라 `localStorage` 저장이 막히므로 HTTP로 여는 편이 좋습니다.

## 배포

GitHub Pages(`main` 브랜치 루트)로 서비스합니다. 저장소 루트의 `index.html`이 그대로 공개 페이지가 됩니다.

```bash
git add .
git commit -m "fix: ..."
git push
```

다른 정적 호스팅도 그대로 됩니다 — Cloudflare Pages(프레임워크 없음/Static), Netlify Drop 등에 폴더째 올리면 됩니다.
